YoYo 把扩散/流匹配模型的后训练拆成可组合的纯函数零件—— 加噪、ODE 求解器、损失函数、奖励模型、模型适配器各自独立、可单测、可复现。 每篇引用的算法都有契约卡、失败模式测试和端到端示例,让 baseline 结果 可核对,而不是一篇 README。

为什么再写一个训练框架

学术对比里,复现一个 baseline 的成本远高于读它的论文。我们把成本降到"装依赖、跑示例"。

Reproducible同一约定,全仓库通用

加噪 x_t=(1−t)x_0+t·noise、Euler/DPM2 求解器、FP32 上溢规则写死在基座层,所有算法共享,杜绝"每篇论文一个符号约定"。

Verifiable失败模式有测试守

不只测"能跑":KL 是否在 FP16 下仍按 FP32 计算、教师目标是否 detach、优势归一化在零方差组是否中性——这些静默 bug 各有断言。

Composable换零件,不换脚本

25 行适配器接入新模型,即可用全部现成目标;新损失写成独立函数注册一行,不与 trainer 主干耦合。

一条实验的晋级阶梯

任何 baseline 从"能构造"到"能引用",必须逐级拿 receipt,不可跳级。

1 · CPU preflight组件可构造、契约成立
2 · GPU no-update前向数值有限、显存可控
3 · one-update一次完整更新,梯度非 nan
4 · checkpoint readback写出读回,SHA-256 一致
5 · 冻结评估固定权重评估,登记 receipt

五分钟跑通

纯 CPU,无需权重。示例全部由单测守护,README 里的数字与代码同源。

  1. 安装 — pip install -e .(Python 3.11/3.12)
  2. 跑测试 — 85 个数值不变量测试全绿即零件可信
  3. 选目标 — mmtrain compose 问答生成训练蓝图:指标、可视化、晋级建议
  4. 跑示例 — 从 SFT 到 RL 八个示例,各自返回真实指标
$ git clone https://github.com/jackeyloveseven/yoyo $ cd yoyo && pip install -e . $ pytest tests/v2 -q # 85 passed $ mmtrain compose --model krea2 --objective flow_grpo \ --reward hpsv3pp --output blueprint.md

蓝图会列出该目标应监控的全部指标(PPO clip fraction、KL、reward 曲线)、 该做的图(奖励曲线、采样网格)与下一步晋级动作——直接贴进实验记录。
